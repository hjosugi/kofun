==================
Match expressions are not part of this grammar; make this positive when they are
:error
==================

let rank = match level {
  Trace => 0,
  Debug => 1,
}

---

This case does NOT say match arms are forbidden. It records that this grammar
has no match rule at all today, matching spec/grammar.ebnf, so `match` cannot
parse yet. It is here so that adding match makes this case fail loudly and get
converted into a positive assertion that arms parse as arms.

Match arms and the bare `x => body` lambda do not collide. Measured against a
throwaway grammar carrying a match rule: it generated with no new conflicts;
`Trace => 0`, `Floor => lower`, an `if`-expression arm body and a nested
`Some => x => x + 1` all parsed with zero errors; and the arm trees were
identical with and without the bare lambda. An arm begins in pattern position
and a lambda is only reachable from expression position, so the two never
compete.
